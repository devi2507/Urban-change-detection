# Urban-change-detection
Urban Change Detection using OpenCV for land cover classification and encroachment monitoring.

## Aim
To classify aerial images into buildings, roads, vegetation, and water using OpenCV and calculate percentage area of each class.

## Technologies Used
- Python
- OpenCV
- NumPy

## Methodology
1. Image preprocessing
2. HSV color segmentation
3. Morphological operations
4. Contour extraction
5. Percentage area calculation

## Applications
- Urban planning
- Encroachment monitoring
- Smart city development

## How to Run
1. Install requirements:
   pip install -r requirements.txt
2. Run:
   python urban_change_detection.py
